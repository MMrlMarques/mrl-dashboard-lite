# Mrl Dashboard Lite 📊

Um painel executivo leve e responsivo focado na visualização rápida das métricas principais do sistema **Mrl Stock & CRM**. Desenvolvido com o objetivo de desacoplar a interface de visualização da aplicação principal, consumindo os mesmos dados diretamente da nuvem.

## 🚀 Funcionalidades

- **Métricas em Tempo Real:** Visualização do total de produtos em estoque e clientes cadastrados.
- **Arquitetura Desacoplada:** Funciona de forma independente do sistema principal (Mrl Stock & CRM), atuando apenas como um *client* de leitura (Dashboard).
- **Interface Responsiva:** Estilização moderna e responsiva utilizando Tailwind CSS.

## 🛠️ Tecnologias Utilizadas

- **HTML5** 
- **Tailwind CSS** (via CDN para prototipação ágil)
- **JavaScript (ES6 Modules)**
- **Supabase** (Backend as a Service / Banco de Dados)
